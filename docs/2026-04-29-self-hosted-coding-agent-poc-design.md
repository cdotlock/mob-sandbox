## Goal

Build the core of a **remote AI dev environment platform**:
- Agent spawns isolated Docker sandbox → pulls GitHub repo → runs app → returns HTTPS preview URL
- Browser terminal (ttyd) accessible into each sandbox — can run code, fix bugs, run AI agents (Claude Code / Aider) inside
- Sandbox isolation is the core guarantee: code crashes inside the container, not the host

Success criteria (Phase A):
1. `https://openhands.mobai.beauty` loads OpenHands web UI
2. User prompts "clone github.com/X/Y and run it" → sandbox spawns → app runs → preview URL returned
3. Preview URL (`https://sb-<id>-<port>.mobai.beauty`) opens in browser, shows running app
4. `https://term.mobai.beauty` opens a ttyd browser terminal into the sandbox
5. Edit a file in the terminal → visible change in browser (hot-reload or re-run)
6. Destroy sandbox → URL goes dead → no host-side residue

## Domain & TLS

- **Domain**: `mobai.beauty` — already registered on Porkbun ✅
- **DNS**: Stay on Porkbun (no Cloudflare needed for PoC)
- **TLS**: Traefik v3.3 with Let's Encrypt DNS-01 via Porkbun provider
- **Cert scope**: `mobai.beauty` + `*.mobai.beauty` (wildcard covers ALL first-level subdomains)
- **Preview URL pattern**: `https://sb-<sandboxId>-<port>.mobai.beauty` — single-level subdomain, covered by wildcard
  - ⚠️ NOT `*.preview.mobai.beauty` (that'd be a second wildcard level, LE doesn't issue `*.*.domain`)
- **ACME flow**: staging endpoint first → verify wildcard signs → switch to production
- **Rate-limit guard**: staging first prevents hitting LE's 50 cert/week/domain limit during resets

## Stack

```
Traefik v3.3
  - listens :80/:443, HTTP→HTTPS redirect
  - DNS-01 wildcard cert (mobai.beauty + *.mobai.beauty) via Porkbun provider
  - Routes: openhands.mobai.beauty, daytona.mobai.beauty
  - Daytona proxy handles *.proxy.mobai.beauty natively (no extra Traefik config)

Daytona OSS  (docker compose, 11 services)
  - API / Runner / Proxy / SSH Gateway / Dashboard
  - Postgres / Redis / Dex OIDC / Snapshot Manager / Registry / OTel
  - Web Preview Proxy: https://<port>-<sandboxId>.<node>.proxy.mobai.beauty  ← built-in
  - SSH Gateway: ssh -p 2222 <user>@<node>.mobai.beauty → enter any sandbox
  - Git integration: daytona create <github-url> → clone + start sandbox

OpenHands V1
  - Image: docker.openhands.dev/openhands/openhands:latest
  - Web UI at: https://openhands.mobai.beauty
  - LLM: DeepSeek via OpenAI-compatible API
    - base_url: https://api.deepseek.com
    - model: deepseek-v4-pro
    - api_key: from .env
  - Sandbox backend: Daytona runtime (All-Hands-AI/third-parties-runtimes)
    - OpenHands → Daytona API → sandbox container → agent tools run inside

Sandbox base image (custom, built on VM)
  - Base: ubuntu:24.04
  - Includes: git, node 20, python 3.12, bun, curl, vim
  - Claude Code CLI  (`npm install -g @anthropic-ai/claude-code`)
  - ttyd (browser terminal within each sandbox)
  - Configured with: ANTHROPIC_API_KEY from .env (for Claude Code inside sandbox)
```

## Execution Model

**Variant 1 — operator-driven**: Claude Code drives everything from user's local Mac via:
- `vultr-cli` → provision VM, inject SSH key
- `curl` Porkbun API → register domain, set wildcard A record
- `ssh` into VM → install docker, configure Traefik, deploy Daytona + OpenHands
- Browser smoke test via `curl`

User touches nothing after handing over credentials.

## End-to-End Verification

```bash
# 1. TLS cert is real LE cert
echo | openssl s_client -connect openhands.mobai.beauty:443 2>/dev/null \
  | openssl x509 -noout -issuer | grep "Let's Encrypt"

# 2. OpenHands web UI reachable
curl -sI https://openhands.mobai.beauty | head -1   # HTTP/2 200

# 3. ttyd terminal reachable
curl -sI https://term.mobai.beauty | head -1         # HTTP/2 200

# 4. Sandbox smoke test (via OpenHands API or manual UI):
#    Prompt: "clone github.com/<owner>/<repo>, run dev server"
#    → wait for sandbox container to appear in `docker ps`
#    → OpenHands returns preview URL sb-<id>-<port>.mobai.beauty
#    → curl that URL → expect HTTP 200 with app HTML

# 5. Sandbox isolation: docker stop <sandbox-id> → preview URL returns 502 → host still healthy
```

## Key Risks & Mitigations

| Risk | Mitigation |
|---|---|
| LE rate limit from repeated Traefik resets | Use staging endpoint first; switch to prod only once flow verified |
| LE rate limit on cert resets | Staging endpoint first; prod only once staging wildcard verifies |
| OpenHands V0 API (deprecated 2026-04-01) | Pull latest tag only — V1 images exclusively |
| ttyd session hijack (no auth) | HTTP Basic Auth via Traefik middleware on term.mobai.beauty |
| Sandbox container breakout | Phase A: acceptable (PoC). Phase C: switch to gVisor/kata for hardening |
